- The compiler scales linearly with the size of a catalog. At 20,000 messages × 10 locales, `runic-translations validate` takes about 5 s instead of 50 s, and the language server shows the first diagnostics of a newly opened file about four times sooner. Two lookups scanned all the messages, or all the lines of a file, once for each message; every message was parsed twice; and files are now read, and messages compiled, on all processor cores. Diagnostics and generated files are unchanged.
