- A generated catalog no longer leaves its locale data's inflate buffers in `ArrayPool<byte>.Shared` after a locale's first use. The pool kept a power-of-two array of at least the inflated JSON and a copy of the DEFLATE data for the life of the process, about twice the inflated data: 557 KB for the Translations Editor's 1,000 messages and about 8.7 MB for a catalog of 20,000. The locale data is now inflated into an array of exactly its length, which is collected once the values are read; first use takes as long as before.
