- Generated output and packs carry markup contract version 3, version 2 without the message entries of the default shape (no slots, not structured, inline content, each locale its own content locale), with the catalog's locales listed once instead (D077.16). This changes the C# a project generates for a 0.15 runtime, the ESM output's `dynamic.js` (`rmf2Contract`) and every locale artifact and pack; message modules are unchanged. Both runtimes read versions 2 and 3 and compare them as one contract, so a 0.15 application loads the version 2 packs written for it, as exact packs and as overlays. C# generated for a runtime before 0.15 keeps version 2, and the caller fingerprint does not change. The format is in [RMF2 execution profile v2](https://github.com/Runic-Artifex/runic-translations-sdk/blob/v0.15.0/specs/translations/rmf2-execution-v2.md#markup-contract-version-3).
