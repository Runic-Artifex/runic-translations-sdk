- Generated C# accessors with one input call one shared body per input type (`__Format_string`, `__FormatContent_int64` and so on), and those with several inputs pass their arguments as a collection expression, a span on the stack. A call no longer allocates an argument array, and a NativeAOT executable grows by about 143 bytes per message instead of 198 (the size probe, 30 % of its messages with inputs). Public members, their signatures and `GeneratedNameVersion` are unchanged; only the generated private members differ, so rebuild to get the smaller code.
