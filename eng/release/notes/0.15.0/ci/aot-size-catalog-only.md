- The NativeAOT size budget `aot/translations/per-message-bytes` measures the generated catalog apart from the size probe's own code (`tests/aot-size`): the probe formats each message from its own non-inlined method and leaves `Main` and those methods out of the catalog's records. The budget no longer moves with how much ILC inlines into one large `Main`; a catalog costs 67 bytes per message there, of which 46 bytes of the former 113 were the probe's call sites.
