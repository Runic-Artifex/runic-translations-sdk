- **Use Runic DevKit 0.22 or later with the 0.15 language server.** The language server speaks only protocol
  revision 2 now ([details](#breaking-changes)). Runic DevKit 0.22 and later, for VS Code and Visual Studio 2026,
  always ask for it. The Runic extensions of runic-editors 0.21 and earlier report a palette refactoring (Rename Input,
  Rename Slot, Rename Resource, Extract Group, Inline Resource) as failed although the server made the edit: update
  them. Other LSP clients need no change, and `runicProtocol` can be removed from their configuration
  ([language server guide](https://github.com/Runic-Artifex/runic-translations-sdk/blob/v0.15.0/docs/guides/translations/language-server.md#protocol-revisions)).
