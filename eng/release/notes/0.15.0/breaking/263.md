- The language server no longer speaks protocol revision 1, the Translations 0.13 behaviour that 0.14 kept for a
  client without `initializationOptions.runicProtocol: 2`
  ([#263](https://github.com/Runic-Artifex/runic-translations-sdk/issues/263)). Every client gets revision 2, and
  `runicProtocol` is ignored: `runic.renameResource`, `runic.renameInput`, `runic.renameSlot`, `runic.extractGroup`
  and `runic.inlineResource` apply their edit through `workspace/applyEdit` and return `null` (a client without
  `workspace.applyEdit` still receives the `WorkspaceEdit`); `prepareRename` and the `refactor.extract` and
  `refactor.inline` code actions are always offered; an unknown request is `MethodNotFound` (-32601) instead of
  `null`, and a request that cannot be carried out is `RequestFailed` (-32803) instead of `InvalidParams`;
  `serverInfo.version` is the tool's version instead of `1`; and the server registers its file watchers, or watches
  the workspace itself, for every client.
