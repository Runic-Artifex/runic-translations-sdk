# Runic Translations 0.6.0-preview.3

## Vite and SvelteKit

- During `vite dev`, saving an `.rmf2` file now updates the text that components
  render. Before, Vite logged a hot update, but the browser kept the previous
  generated messages until a reload. Text computed in a server `load` function
  still updates on reload, as with any SvelteKit server module.
