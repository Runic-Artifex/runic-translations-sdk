# Runic Translations 0.7.0-preview.2

## Runic.CommandLine text

- `Runic.Translations.CommandLine` and `Runic.Translations.Tooling` now require
  Runic.CommandLine 0.7.0-preview.1 or later. The built-in English and German
  catalogs translate its new text keys: the `CommandPrompts` hints, Yes and No
  answers and errors (`prompts.*`), the `diagnostics.prompt-*` messages of an
  `RCLI4001` prompt that cannot ask, the JSON output alias in help
  (`help.json-output-alias`) and `diagnostics.conflicting-output-selector`.
- The built-in catalogs leave `faults.RCLI4001` undefined, so Runic.CommandLine
  keeps showing the more specific `diagnostics.prompt-*` text for that fault.
