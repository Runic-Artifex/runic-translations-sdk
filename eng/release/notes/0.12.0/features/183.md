## Message markers for inspectors

([#183](https://github.com/Runic-Artifex/runic-translations-sdk/issues/183))
Under `vite dev`, the text-change channel gains a `markers` member, so an
inspector can tell which message an element on the page shows. runic-sdk's
Runic Inspect uses it in select mode
([runic-sdk#956](https://github.com/Runic-Artifex/runic-sdk/issues/956)).

- `markers.set(true)` turns marker mode on and renders the page again, as a
  text edit does. Every `m.key()` call then puts an invisible marker in front of
  its text (the first text of an inline or document message) that names the
  message's catalog, key and locale. `markers.decode(text)` lists the messages a
  text contains, and `markers.strip(text)` removes the markers.
  `markers.set(false)` renders the plain text again.
- Marker mode is off unless an inspector turns it on, so text, `textContent`,
  copied text and tests are unchanged. The markers are invisible format
  characters (U+2061–U+2064) that take no width.
- It is part of the serve-only rewrite of message modules. The generated
  runtime and production builds are unchanged.

See [Message markers](https://github.com/Runic-Artifex/runic-translations-sdk/blob/v0.12.0/docs/guides/translations/esm.md#message-markers).
