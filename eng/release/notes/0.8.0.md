# Runic Translations 0.8.0

## WPF

- `WpfInlineRenderer` and `WpfDocumentRenderer` accept an already linked
  `Rmf2MarkupContract`, so an app with an inline and a document renderer links
  its catalog's contract once instead of once per renderer:
  `new WpfInlineRenderer(contract, navigate)` and
  `new WpfInlineRenderer(contract, navigate, new WpfInlineRendererOptions { Custom = …, Theme = … })`,
  with `WpfDocumentRendererOptions` for the document renderer. The constructors
  that take the contract JSON are unchanged and now link it once per renderer
  instead of parsing it twice.
