## Smaller NativeAOT executables (#216)

A trimmed or NativeAOT publish no longer links .NET's reflection stack for Translations Hot Reload. The Hot Reload
check (`MetadataUpdater.IsSupported`) is now a constant there, so the trimmer removes the catalog tracking and the
reflection it used. In a console application with a generated catalog, this saves about 350 KB on linux-x64. A Debug
build and `dotnet watch` still apply edited catalog text in place, as before. The runtime's argument checks also no
longer call `Enum.IsDefined`.

`tests/aot-size` measures a NativeAOT probe with a generated catalog, and CI checks its size budgets.
