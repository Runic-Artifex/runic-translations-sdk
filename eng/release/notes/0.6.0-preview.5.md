# Runic Translations 0.6.0-preview.5

## WPF XAML binding

- `Runic.Translations.Wpf` binds generated messages in XAML. `TranslationSource`
  wraps a manager and the generated `Messages` surface;
  `{rt:Message orders_greeting, Arg0={Binding UserName}}` binds plain messages
  with inputs from the DataContext, and `rt:Translations.RichMessage`,
  `Slots`, `Arguments` and `Source` render messages with markup into a
  `TextBlock` through `WpfInlineRenderer`. Bindings refresh on `LocaleChanged`
  on the right dispatcher and hold their elements weakly. `RefreshAsync` never
  raises `LocaleChanged`; use `TranslationSource.RefreshAsync` or `Invalidate`.
  See the new "WPF quick start" in the package README.
