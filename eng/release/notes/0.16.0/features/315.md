## Capability matrix version 2 ([#315](https://github.com/Runic-Artifex/runic-translations-sdk/pull/315))

`specs/translations/capabilities-v2.json` lists the implementations of the Translations contract as an open set of
keys, each with its status (`development`, `preview` or `stable`) and the source of its localized dates and times, so a
new implementation such as a Rust runtime is added without a new matrix version. `runic-translations schema` writes
its schema, `capabilities-v2.schema.json`, beside the others. Version 1 (`capabilities-v1.json`, with the closed
`backends` tuple `dotnet`, `esm`) is frozen and still generated. See the
[capability matrix](../../../specs/translations/capabilities.md).
