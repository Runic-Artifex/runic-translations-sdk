# Runic Translations Editor 0.1.0

The first release of the Translations Editor on its own version line (D078). Until now the editor shared the version
of the Runic Translations packages it is built from; from 0.1.0 on it has versions of its own, plain `0.y.z` before
1.0, and releases of its own in this repository, tagged `editor-v<version>`. This release is built from the same
source as Runic Translations 0.15.0.

Download the package for your system from the release's assets and check it against its `.sha256` file. The packages
are unsigned: see [Download and install](https://github.com/Runic-Artifex/runic-translations-sdk/blob/editor-v0.1.0/apps/translations-editor/docs/editor-distribution.md#download-and-install)
for the steps on each system, including macOS Gatekeeper and Windows SmartScreen.
