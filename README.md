# Runic Translations SDK

Runic Translations provides deterministic RMF2 compilation, runtime libraries, build integration, editor tooling, IDE extensions, and Vite integration. It is independently versioned and released from the application SDK.

Use `direnv allow`, then `bun run bootstrap`, `bun run build`, and focused `dotnet run --project tests/dotnet/Runic.Translations.Compiler.Tests` checks. Product guides are canonical in `docs/guides/translations`; schemas are canonical in `specs/translations/schemas`.
